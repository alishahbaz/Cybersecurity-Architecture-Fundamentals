# Cybersecurity Architecture Fundamentals

This wiki provides an easy-to-read reference for fundamental cybersecurity architecture principles.

It is based on the video series covering:

- **Fundamentals** — core security principles that should apply to everything you do
- **Cybersecurity domains** — how to identify vulnerabilities, apply best practices, and defend against threats through a complete security architecture

This package focuses on the **fundamentals**.

## What You Will Learn

You will learn the five security principles you should **always** observe:

- [Defense in Depth](https://github.com/alishahbaz/Cybersecurity-Architecture-Fundamentals/wiki/Defense-in-Depth)
- [Least Privilege](https://github.com/alishahbaz/Cybersecurity-Architecture-Fundamentals/wiki/Least-Privilege)
- [Separation of Duties](https://github.com/alishahbaz/Cybersecurity-Architecture-Fundamentals/wiki/Separation-of-Duties)
- [Secure by Design](https://github.com/alishahbaz/Cybersecurity-Architecture-Fundamentals/wiki/Secure-by-Design)
- [KISS](KISS)

And the one principle you should **never** rely on:

- [Security by Obscurity](https://github.com/alishahbaz/Cybersecurity-Architecture-Fundamentals/wiki/Security-by-Obscurity)

## Why These Principles Matter

In the real world:

- attackers are persistent
- systems are complex
- people make mistakes
- no single control is perfect

That is why strong security architecture is based on **multiple, layered, and practical controls** instead of relying on one tool, one password, one wall, or one secret.

## Simple Mental Model

```text
Good security =
  multiple layers
+ limited access
+ separation of roles
+ security built in early
+ simple enough to use
- dependence on secrecy
```
